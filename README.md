# Commandor — кадры и реплики

HTML-галерея: главы 1–3, 73 кадра 9:16 с действиями для видео и репликами.

Все превью встроены в `index.html`. Полные исходники, отдельные оригиналы изображений, референсы и документы в этот репозиторий не включены.


46 аудиозаписей Кеммера размещены в `audio/` и связана с репликами К001–К041. Плееры доступны в карточках и увеличенном просмотре; одновременно играет одна запись. Для локального воспроизведения сохраните `index.html` вместе с папкой `audio/`.

Для реплики К007 (кадр 017) под болванкой расположен плеер переделки с выбором одного из пяти голосов. Выбор сохраняется при переходе в увеличенный просмотр и обратно; смена голоса останавливает запись и начинает выбранный вариант с начала.
