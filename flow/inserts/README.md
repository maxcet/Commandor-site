## Состав

- ВСТ01: Кабинет. Чистый общий вид кабинета. Использовать как вступление до разговора: в видимом кресле нет Кеммера.
- ВСТ02: Настенная карта. Основной вариант первой предметной вставки. Акцент на карте мира и районе Кербенна.
- ВСТ03: Разлом. Более тревожная альтернатива карте: слово «Разлом» и соседний Кербенн. Подойдёт также к упоминаниям Разлома.
- ВСТ04: Императорский указ. Указ целиком: назначение Аделины Боллар и отсутствие утверждающей подписи. Печать уточнена по отдельному референсу.
- ВСТ05: Пустая подпись. Главная смысловая вставка под «Я не подпишу ваше назначение». Строка остаётся пустой.
- ВСТ06: Восковая печать. Уже существующая восковая печать императорского указа. Это не чернильная личная печать Кеммера из сцены отказа.
